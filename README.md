# aktivschool_bot

Прототип чат-бота школьного конкурса «Ценность месяца».

## Ссылки для второго тура

- Готовый бот MAX: [https://max.ru/aktivschool_bot](https://max.ru/aktivschool_bot)
- Репозиторий GitHub: [https://github.com/amaev8595-design/aktivschool_bot](https://github.com/amaev8595-design/aktivschool_bot)

В репозитории находятся:

- `app/Dockerfile` — инструкция сборки Docker-образа приложения;
- `docker-compose.yml` — запуск приложения вместе с PostgreSQL;
- `requirements.txt` — библиотеки Python и зафиксированные версии;
- `.env.example` — пример настроек без секретов;
- этот README — инструкция запуска и описание проекта.

## Запуск из командной строки

Откройте PowerShell в папке проекта:

```powershell
cd "C:\Users\ALFA\Desktop\Проект актив\aktivschool_bot"
```

Создайте локальный файл настроек и укажите в нём токен MAX и пароль базы данных:

```powershell
Copy-Item .env.example .env
notepad .env
```

Соберите Docker-образ приложения из `app/Dockerfile`:

```powershell
docker compose build app
```

Команда создаёт локальный Docker-образ `aktivschool_bot-app`. Сам бинарный
образ не хранится в Git как архив: он воспроизводимо собирается из
`app/Dockerfile` и `requirements.txt`.

Запустите контейнер приложения и PostgreSQL:

```powershell
docker compose up -d
```

Проверьте состояние контейнеров и логи приложения:

```powershell
docker compose ps
docker compose logs -f app
```

Остановите проект:

```powershell
docker compose down
```

## Первый запуск

1. Скопируйте `.env.example` в `.env`.
2. В `.env` укажите токен MAX в переменной `MAX_BOT_TOKEN`.
3. Запустите проект:

```powershell
docker compose up --build
```

4. Откройте бота MAX и нажмите системную кнопку `Start`. В локальном режиме
   polling можно использовать команду `/start`.

Остановить проект:

```powershell
docker compose down
```

Данные PostgreSQL хранятся в именованном томе Docker `pgdata`.

## Текущий этап

Сейчас реализованы главное меню с тестовыми разделами, эхо-ответы, демонстрационный список классов и подключение к PostgreSQL. Список классов загружается из `app/data/classes.csv`. При запуске приложение создаёт начальные таблицы для классов, пользователей, идей, мероприятий, отчётов, баллов и настроек.

Первый вход: отправьте `/start` и выберите тип регистрации. Для ученика нужен
код приглашения класса; для учителя — персональный код, созданный администратором.
Для демонстрации регистрации ученика используется код `AKTIV-9A`.

Регистрация учителя проходит в три шага: ФИО, предмет и персональный код.
После отправки заявка появляется у администратора в разделе «👩‍🏫 Заявки
учителей». Только после одобрения пользователю назначается роль `teacher` и
привязывается класс. Код учителя одноразовый и должен передаваться лично.

Команда `/myid` показывает технический ID пользователя MAX. Чтобы назначить себя администратором, внесите этот ID в локальную переменную `ADMIN_IDS` файла `.env`, перезапустите приложение и отправьте `/start` или `/admin`.

Администратор может назначить дополнительных администраторов через кнопку
«🛡 Назначить роль» или командой `/setrole ID admin`. Снять права последнего
администратора нельзя. Пользователей, указанных в `ADMIN_IDS`, также нельзя
понизить через команду.

В нижней клавиатуре доступны кнопки «ℹ️ Инструкция» и «▶️ Старт». Кнопка
«▶️ Старт» возвращает к начальному экрану, а «ℹ️ Инструкция» показывает краткое
описание сценариев.

Системная кнопка запуска MAX обрабатывается событием `bot_started`. Для её
работы бот должен быть подключён в режиме webhook с публичным HTTPS-адресом;
локальный режим polling обрабатывает текстовую команду `/start` и кнопки из
сообщений.

Кнопка «⚙️ Администрирование» открывает панель с русскими кнопками. Формы
добавления класса, мероприятия, роли, лимита, идеи, отчёта и призовых баллов
запрашивают данные пошагово. Slash-команды остаются доступными как резервный
вариант, но в панели администратора больше не отображаются.

Администратор может использовать команды:

- `/setvalue Текст ценности месяца`
- `/addclass Название|группа|код`
- `/addevent Название|Описание|YYYY-MM-DD|Класс`
- `/classes`
- `/events`
- `/users`
- `/setrole ID admin|moderator|teacher|student`
- `/teacher_applications`
- `/teacher_codes`

Учитель после назначения роли и привязки к классу может создать мероприятие
для своего класса командой `/addevent Название|Описание|YYYY-MM-DD`.
Администратор указывает класс отдельно: `/addevent Название|Описание|YYYY-MM-DD|Класс`.

Кнопка «👥 Пользователи» сначала предлагает выбрать категорию: ученики, учителя
или администраторы. После выбора бот показывает список числовых ID пользователей
и привязанный класс. Для одобренных учителей дополнительно показываются ФИО и
предмет. Команда `/users` открывает тот же сценарий.

Для работы с классами администратор может выбрать «🗑 Удалить класс». Пустой класс
удаляется только после подтверждения. Если с классом связаны пользователи,
мероприятия, отчёты или баллы, бот блокирует удаление и предлагает архивировать
класс с сохранением истории.

Кнопка «🎪 Афиша» показывает одобренные мероприятия. Участник с привязанным
классом может записать класс командой `/signup Номер мероприятия`.

В главном меню также есть русские кнопки «📍 Место» и «👥 Команда»:
первая показывает позицию класса в рейтинге, вторая — класс и число его
участников в системе.

Пользовательские разделы работают с контекстными кнопками: в афише есть кнопка
«🤝 Принять участие». После её нажатия список мероприятий остаётся на экране,
а ниже появляются кнопки с номерами мероприятий для записи. Пользователь не
видит кнопку добавления мероприятия: предложить вариант можно через «💡 Подать
идею».

После участия пользователь открывает в афише кнопку «📋 Подать отчёт» и
выбирает мероприятие из списка. Затем вводит комментарий, при необходимости
прикрепляет фото или видео и подтверждает отправку кнопкой «✅ Отправить
отчёт». Старый вариант через команду также поддерживается:

- `/report Номер мероприятия|Комментарий`

Фото или видео можно прикрепить к этому же сообщению с командой. Например,
отправьте фото с подписью `/report 1|Провели мероприятие, участвовали 18 учеников.`

Для защиты очереди один класс может отправить только один отчёт по одному
мероприятию. Повторная отправка от другого участника того же класса также
блокируется, поэтому получить дополнительные баллы за одно мероприятие нельзя.
Если модератор отклонил отчёт, его автор получает уведомление и может исправить
существующий отчёт через кнопку «📋 Подать отчёт» — новый отчёт при этом не
создаётся.

Модератор проверяет отчёты командами `/reports`, `/approve_report Номер` и
`/reject_report Номер Причина`. Подтверждённый отчёт начисляет классу 5 баллов.
Кнопка «🏆 Рейтинг» показывает баллы из PostgreSQL.

Модерация идей:

- `/ideas`
- `/approve Номер`
- `/reject Номер Причина отклонения`

Очередь отчётов открывается отдельной контекстной клавиатурой: в ней остаются
только кнопки «✅ Одобрить отчёт» и «❌ Отклонить отчёт». Номер отчёта и причина
отклонения вводятся последовательно, после чего действие подтверждается.

Одобренная идея автоматически становится мероприятием в афише с датой через
7 дней. Автор получает уведомление об одобрении или отклонении, а модераторы
получают уведомление о новых идеях и отчётах.

Лимиты и баллы:

- по умолчанию не более 3 идей от одного класса в месяц;
- по умолчанию не более 5 одобренных идей одного класса в месяц;
- подтверждённый отчёт начисляет баллы участия из настройки `points_scale`;
- призовые баллы выдаются командой `/award Класс|Место`;
- лимиты можно изменить командами `/setlimit ideas|Число` и
  `/setlimit approvals|Число`.

Подача идеи работает в три шага: название, описание и целевая группа. Для отмены сценария используется `/cancel`.

Следующий этап — совместное финальное тестирование и исправление найденных ошибок.

## Режимы запуска

Для локальной разработки используется polling:

```text
BOT_MODE=polling
```

Для демонстрации через публичный HTTPS-адрес в `.env` укажите:

```text
BOT_MODE=webhook
WEBHOOK_PUBLIC_URL=https://ваш-домен.example/webhook
WEBHOOK_SECRET=секрет-длиной-не-менее-пяти-символов
WEBHOOK_DOMAIN=ваш-домен.example
```

После настройки DNS и открытия портов 80/443 запустите приложение вместе с
Caddy-прокси:

```powershell
docker compose --profile webhook up -d --build
```
