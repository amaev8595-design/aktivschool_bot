# aktivschool_bot

Прототип чат-бота школьного конкурса «Ценность месяца».

## Первый запуск

1. Скопируйте `.env.example` в `.env`.
2. В `.env` укажите токен MAX в переменной `MAX_BOT_TOKEN`.
3. Запустите проект:

```powershell
docker compose up --build
```

4. Откройте бота MAX и отправьте `/start`.

Остановить проект:

```powershell
docker compose down
```

Данные PostgreSQL хранятся в именованном томе Docker `pgdata`.

## Текущий этап

Сейчас реализован минимальный эхо-бот в режиме long polling. При запуске приложение подключается к PostgreSQL и создаёт начальные таблицы для классов, пользователей, идей, мероприятий, отчётов, баллов и настроек.

Следующий этап — регистрация пользователя, роли и коды приглашения классов.
